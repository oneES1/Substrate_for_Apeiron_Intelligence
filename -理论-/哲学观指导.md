# 已见、未见，连同我们和我们的解释，内容于自然，自然使然

（基本元素：自然；内容，），
- 内容包括内涵，全体内容的集合定义为自然。
- 此处的自然不是狭义的自然科学，它包括了一切。例如如果信奉唯心主义，那她就自动变成对应那个最根本的概念，把“自然”换一个词其学说喜欢的词。本理论作为框架没有观点倾向，“自然”只是作为一个内涵去表述行文。

（工具概念：内涵，世界，划分，映射），
- 内涵：对应内容在特定映射出的“一个”被理解的可操作的对象（一般的映射是内容对内容，不强调一个，也不强调被理解）
- 世界是对自然划分出的一种内容的集合，并不要求自洽
- 不同内容间单或双向的影响，被称为映射，定义为：A，B内容间，借助内容C构成互相影响称作映射。但C往往复杂且难以内涵，因此文中涉及映射时使用“A，B世界之间作用”等这类省略C的表述。

  一切都在自然之中。熟知的物质与概念、规律与现象，在这里具有同样的地位。“物质”与“概念”的区别，是对自然中的内容作出的一种划分，这个划分本身（概念）也属于自然。关于自然的解释，连同它所谈论的内容、它的形成与作用，都在其中。这里并没有严格定义什么是物质与概念，在这里也不应该过度关心（比喻：纠结这个就相当于纠结在空间里选什么基底一样，但我们关心的是空间本身。）
  
  世界与划分的理解可以这样举例，比如两个不同的人对同一件事情的理解，每个人分别与这件事划分为一个世界，这件事就是世界相交的地方，而 1. 每个人 以及 2. 他们的理解思考（内涵）是不同的内容，是这两个世界不相交的地方。自然本身就是一个世界，在其内容中划出一定的范围，也就得到一个世界。范围中可以有无限丰富的内涵。几个世界可以彼此包含、彼此分离，也可以相交。相交处就是这些范围共同涵盖的那部分自然。谈论不同世界，始终是在同一个自然中谈论它们。
  澄清：划分是人为的操作，比如“内心世界”的范围，可以取整个人，包括身体和思想；可以取大脑；也可以只取思想。对于本文“内心世界”，没有固定采用其中一种。
   进一步理解“世界”与“划分”形成的结构：内心世界属于自然，其中又可以有对自然的认识。借一个比喻来理解，可以把自然想象成一个庞大的交谈者：人同它接触、探索它的规律，如同在交谈中逐渐领会对方的思想。人同人的交流，以及人与周围世界的接触，在这个比喻中显出相通的关系。交谈者、所谈论的内容和交谈本身，都在自然之中。其中有趣的是，作为自然内容的一部分，我们可以探索和理解“人”是什么。此外，”物质与概念、规律与事物具有同样的地位“的意思可以在这个比喻里被更好感悟。补充例子[1]
  澄清：并不会出现理发师悖论似的世界套世界的集合结构，例如在“内心世界理解认识自然”这类结构中，并没有把自然世界套入内心世界，自然被映射进内心世界，内心世界里映射了对各个自然中的其他内容的理解。且他们也属于自然里的内容。
  
  补充对映射的理解，可以把ABC放在更大的世界里看：两个分离的AB世界之间发生交流，把双方及其沟通手段C一同纳入更大的范围，这段交流就在这个更大划分范围的世界内部发生。双方和它们之间的作用C，都属于自然。为了清晰文章，后面我们用到映射时，省略“映射”和C的文字说明。
  
  这套体系里最为尊重的是自然内容运动*（时间刻度视角下，我们论述使用），我们的行动与其他各种运动是自然得驱动支配：产生理论，用内涵去描述自然，因果推断，现象发生描绘等是在解释和创造解释，我们的操作和行动是自然内容。自然自己在运动，动出了各种内容，包括动出了我们和我们的解释。（预测也是一种解释；指定内容C下，好的解释可以把理论内容（A）描绘的后果与自然（B）映射）[0]
  例如“自然运动下我们产出了一个物理理论，我们在物理理论指导下做了什么事情”。这一现象就是自然内容运动出现的一个表象，当然不会解释为物理定律正确或者他生效了。对 “通过解释或者我们改造了自然” 这个论题的解释是：因为都归属自然，所以在这一体系定义下也是自然的支配，并不依赖解释是否正确或者人怎么样。更准确地说，所有内容都应该不能单独运动，因为我们在谈运动的时候，只能谈自然的运动、自然内容的运动。再强调一下，说到运动，这里已经默认了时间，这个说法的地位需要分清。
  但上述侧重说自然“运动”自己的闭合意味。（内容的内涵部分）当然可以显得“无意义”，也不需要定义意义。
  澄清的是：自然归属自然不意味着决定论，也没约束自由意志等议题。这些议题归属于二级子课题。同样的，上述时间刻度真实存在还是符号也是二级课题。


  现用这套体系刨析一个“物理理论与内心，自然关系“的例子先作为理解巩固：一个物理理论的**内容**也承载着一个世界，其中有它所描述的事物、规律和过程。这个世界有自己的范围，其内容可以远远超出提出理论的那个人已经认识的部分（一般物理理论世界里的内容与每个人脑中映射的内涵不一样）。理论中的一些关系，也可以在某个人发现它们以前就已经属于自然（这本质涉及到时间是否是幻觉的议题，这不是我们现在关注的）。理论世界与内心世界相交时，交集是两者共同涵盖的那部分理论内容。一个人的发现与表达，应用，可以是这个理论世界与自然的其他内容映射过程的世界C的组成部分。
  借此处阐述清楚“内涵”与“普通内容”的区别：同一理论可以换用不同的语言和符号，可以用不同方式说明同一现象，在相同条件下给出一致（这里的一致指的是给出同一内容，泛泛的相同实验现象不等于一致）的预测。我们一直强调内容的重点在于，这些形式及其等价关系是对同一理论内容的不同内涵映射。例子[2]

  前文提到世界不要求自洽，世界是对内容的一个划分，此处用“小说”做以说明：小说里可以有零散的无体系内容，虽然世界内部不自洽，他们仍可以与其他内容交互。换句话说，世界本来就是划分出的，我们将小说与人类社会做划分，在这世界中看小说在这一世界里地位就更加自洽。创作、阅读和流传又使这些内容参与其他活动，影响思考及随后发生的行动。

  为激进展现上文所谓的“理论去解释自然内容运动”在这一哲学中如何体现，设想一套能够很好地逼近自然的物理理论。这套理论展开的世界足以近似刻画描述自然内容，做一个有益的类比：类似可数无穷近似刻画不可数无穷，在这里人文艺术、无逻辑陈列归属于“无理数集合”里，但我们可以去用可数去描绘无理数：人表达没有逻辑的话时，仍然可以用还原论的拆解去解释说胡话这个过程的人怎么被分子原子运动支配说出胡话。要注意的关键区别是，这里划分的物理世界并没有包含自然里胡话内容，他们分别是自然划分出的两个不相交内容（可以定义为世界），其中该物理世界的内容映射了对自然的理解，我们只是在上述例子展示：虽然胡话和艺术（属于自然的内容）不归属这套理想理论世界里划分的世界，但物理世界仍然可以去映射和推演他们。例子[3]

  需要注意的是，自然不可知，足够好的理论原则上只是一个内容里的一种符号体系呈现，目的是方便笔者做论述说清楚，理论不可穷尽自然，还原没有尽头。一个世界里有无穷内容的表述可以更近一步区分：就算按一套公理表示的世界里，他范围内的内容，可以挖掘出无数的概念。可以谈涌现，也可以谈单纯的概念堆积。我们接上文章开头重新理解：物质与概念地位相同，我们通称为内涵，自然由内容填充，划分内容可以定义世界。一个内容里可以映射无数内涵。

1. 时间刻度的存在性：
   I - 我们如果认为真实发生、形成和增长，接受时间存在，内容确实在过程中产生、变化。那么我们可以上帝视角给出内容的历史的真实增长，如果加上“删和遗忘”的历史不可追溯感觉，那就是某种筛选选择历史的窗口解读角度。我们构建的理论解释自然的发生，预测则沿这种时间表达指向未来。
     
   II - 如果我们认为时间是错觉，**整体已经给定。** 全部内容及其关系都在其中。那么可以认为内容间的作用与依赖可以形成链状联系，其集体关系呈现出先后、因果刻度。这种理解也能够交代我们所体验到的时间感。

## 其他例子（未维护，看了不一定有好处）

[0] 从手和眼，到造出工具

（这里借"公设"这个说法来讲：公设指一件事里先拿来依赖的起点。它是讲述用的工具，哲学本身用不到它。）

一个人最初靠手和眼接触周围，这是最早的两个公设。可以把公设看成函数：它怎样作用于外部，能带回什么结果。同别人沟通也是这样一个函数。

靠手和眼，人造出锤子和显微镜。新工具也是新的公设，后面的事情可以从它们出发。

发展到一定程度，人有了理论，回头能解释手为什么能工作、眼为什么能工作。原来当作起点的手被拆开，拆出更基础的公设；用物理作比，就是物理定律加原子这一类东西。沟通、投射、观察也能这样被解释，例如今天可以讲清卷积网络分辨图像时内部发生了什么。拆出来的更基础的公设又能构造新东西，理论接着指导人造新的工具、找新的观察方法，循环由此继续。

用正文的话看这段经过：手、眼、工具、沟通和观察，一直是自然里的内容，有人解释它们以前就已经在。"公设"是我们后来对它们的解读，这个解读是一份内涵。理论解释了手怎样工作，手照旧那样工作。人拿着理论去造显微镜，这整件事是自然内容的运动；理论在其中承担解释，包括对下一步结果的预测。从手眼到工具、到理论、再到新工具的这一圈，连同其中每一次解释，都是自然动出来的。

[1] 一个内心世界里再划分

一个人的感受、记忆和思想，可以划成他的内心世界。这个世界里面还能再划。比如一个人对自然有一套看法，对人类社会有另一套看法，可以把它们分别划成两个世界。

面对同一件事，两套看法可能给出不同的解释。沿着其中一套想下去，会引出另一套里的问题，这是两个世界之间的映射；承担沟通的 C 是这个人的思考，它也在这个内心世界里。把两套看法和这段思考合起来看，整个往来发生在同一个内心世界内部。思考时可以把两套看法混在一起用，也可以分开来讨论，两种做法是对同一些内容的不同划分。

往大处取也一样：整个人类可以划成一个世界，里面同样可以再划分。这些世界都在自然之中。

[2] 同一理论的几种形式，和各人的理解

以经典力学为例。牛顿的写法用力和加速度，拉格朗日的写法用作用量；给定同样的条件，两种写法给出同一个运动。两种写法是同一理论内容的两份内涵。

一个人的内心世界可以涵盖其中几种形式，以及它们之间的联系。他可以沿着一种写法往下想，再借另一种写法领会某些关系，在来回之间逐渐把握它们等价在哪里。

思想传播时，各人的理解有差异。有人熟悉理论里的某些关系，有人从另外一些问题进入；同一段论述在各人那里牵连出不同的经验、联想和判断。用世界来说：各人的内心世界与理论世界在不同的部分相交。两个人都涵盖到的那部分理论内容，是他们两个内心世界的交集；各人由此得到的内涵，组织方式和侧重各有不同，留在各自的世界里。

相交说的是范围。两个人的交流是另一件事：它是一次映射，借助语言和文字这些 C 发生。交流就在这样的具体情形里继续。

[3] 一个整体里的活动，划开之后怎么看

沿用正文设想的那套足够好的物理理论，再假设它显含时间（时间在这里是叙述的办法，见二级课题 1）。沿时间展开它所描述的一段活动，例如两个人交谈。

在理论的描述里，这是一段连贯的过程：一个人的身体和大脑、空气里的声音、另一个人的身体和大脑，按同一套规律接续变化。其中每一部分地位相同，都归在同一个世界里。

现在把这个整体划成两个彼此分离的世界 A 和 B，各取一个人。从 A 看，它的运动条件里有一项来自 B 的作用。追溯这一项，就进入 B 形成这个作用的过程；从这一项往后展开，就进入 A 受到作用之后的活动。双方的条件和变化这样互相接续。

同一段活动于是有两种讲法。在整体里讲，它是一段连贯的运动。划开之后站在 A 或 B 讲，它成为"外部对我的作用"和"我向外产生的作用"，于是用到"沟通""观察""投射"这些说法。划分改变的是讲法；活动还是那一段，沟通借助的声音和文字（C）一直在自然之中。把一个人的内部划成两块，会出现同样的情形。

这与正文"把 A、B、C 放在更大的世界里看"是同一个意思，这里沿时间把它展开了一遍。正文的提醒在这里同样适用：理论世界里展开的是对这段交谈的描述，交谈本身是自然里的另一份内容，两者之间是映射。
